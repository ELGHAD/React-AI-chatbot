# 🤖 AI Chatbot (React + OpenAI API)

A modern AI chatbot built with **React (Vite)** and the **OpenAI API**, featuring a sleek chat interface, message bubbles, dark/light mode toggle, auto-scroll, and smooth user experience.  
This project is a **frontend-only demo**, calling OpenAI’s API directly from the browser.

---

## 🚀 Features

- 🗨️ Modern chat UI with bubbles
- 🌗 Dark / Light mode
- ⌨️ `Enter` to send, `Shift + Enter` for newline
- 🔄 Auto-scroll to latest message
- 🧹 Clear chat button
- ⚙️ Easy to customize UI and system prompt
- 🎯 Built with React + Vite for fast development

---

## 🛠️ Tech Stack

| Layer | Technology |
|---------|------------|
| Frontend | React (Vite) |
| Styling | Custom CSS |
| AI Model | OpenAI API (`gpt-4o-mini`) |
| State | React Hooks |
