# React AI Chatbot

A lightweight AI chatbot built with React and Vite, powered by the OpenAI API. This project demonstrates the integration of a large language model into a modern, interactive web interface, with conversation management, dark and light themes, and a streamlined user experience.

The application is designed as a frontend-only demonstration, making it easy to run locally and explore the fundamentals of AI-powered conversational interfaces.

## Overview

React AI Chatbot provides a conversational interface that allows users to interact with an AI model through the OpenAI API.

Built as a single-page application (SPA), it focuses on frontend development, API integration, state management, and user experience without requiring a dedicated application server.

The project provides a practical foundation for exploring AI-powered web applications and can be extended with authentication, persistent conversation storage, and a secure backend architecture.

## Key Features

- **AI-powered conversations:** Send messages and display responses generated by the OpenAI API.
- **Interactive chat interface:** Present conversations using distinct user and assistant message bubbles.
- **Dark and light themes:** Switch between visual themes.
- **Keyboard shortcuts:** Press `Enter` to send a message and `Shift + Enter` to insert a new line.
- **Automatic scrolling:** Keep the latest conversation messages in view.
- **Conversation reset:** Clear the current conversation and start again.
- **Customizable behavior:** Adapt the interface and system instructions to suit different use cases.
- **Modern development workflow:** Use Vite for local development and production builds.

## Architecture

The application follows a frontend-only architecture.

```text
User
 |
 v
React Chat Interface
 |
 v
React State Management
 |
 v
OpenAI API Client
 |
 v
OpenAI API
 |
 v
Generated Assistant Response
 |
 v
Conversation Interface
```

React manages the interface and conversation state, while the OpenAI API generates assistant responses.

**Architecture limitation:** In this implementation, API requests originate from the browser. This is suitable for local experimentation but is not a secure architecture for a publicly deployed application when a private API key is involved.

For production use, requests should be routed through a backend service that securely stores credentials and enforces appropriate access controls.

## Getting Started

### Prerequisites

- Node.js 18 or a compatible version supported by the project dependencies.
- npm.
- An OpenAI API key.
- Access to the OpenAI API with the required billing or usage allowance.

Create an API key through the [OpenAI Platform](https://platform.openai.com/api-keys).

### 1. Clone the Repository

```bash
git clone https://github.com/ELGHAD/React-AI-chatbot.git
cd React-AI-chatbot
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Configure Environment Variables

Copy `.env.example` to `.env` in the project root:

```env
VITE_OPENAI_API_KEY=your_openai_api_key
```

Replace the placeholder with your own API key.

**Important:** Vite exposes variables prefixed with `VITE_` to client-side code. Consequently, this configuration does not protect the API key from users who can access the application. Never use this approach for a publicly deployed application with a private API key.

For production deployments, move API requests to a backend and keep the key in server-side environment variables.

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed by Vite, typically:

`http://localhost:5173`

### 5. Create a Production Build

```bash
npm run build
```

The generated production assets are typically written to the `dist/` directory.

To preview the production build locally, run:

```bash
npm run preview
```

## Security Considerations

This repository is intended as a frontend integration demonstration.

- **API key exposure:** Variables prefixed with `VITE_` are included in client-side application code when referenced by the application.
- **Production architecture:** Use a backend API to protect credentials and control access to the OpenAI service.
- **Usage limits:** Apply server-side rate limiting and usage controls to reduce abuse and unexpected API costs.
- **Input validation:** Validate incoming requests and enforce appropriate message length limits in a production backend.
- **Code quality:** Use ESLint to help identify potential issues and maintain consistent JavaScript conventions.
- **Secret management:** Never commit private API keys or other credentials to version control.

If a private API key has already been committed to a public repository, revoke or rotate it through the OpenAI Platform.
